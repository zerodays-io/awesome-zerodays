## Execution Custody & Sandboxing

- [blackwall](https://github.com/zerodays-io/blackwall) — AI containment layer for agent execution with OS syscall jails and reversible run-custody records.
- **Landlock LSM** — Unprivileged Linux kernel sandboxing for restricting filesystem and network access.
- **Seccomp BPF** — Syscall filtering preventing escape from untrusted agent code runs.

## Incubator Machines & Monorepos

- [terrarium](https://github.com/zerodays-io/terrarium) — Ideation-to-validation incubator machine in one atomic polyglot Moon repository.
- **Atomic Changesets** — Co-locating RFCs, venture data rooms, and runnable prototypes in one versioned tree.

## Legal & Chain of Title Engineering

- **Single Holding Floor** — Consolidating IP, marks, and contracts under one Delaware holding company before entity spin-out.
- **Intra-Group Licensing** — Clear quality-control and licensing mechanisms ensuring commercial use establishes owner rights.
- **Trigger-Based Incorporation** — Incorporating on liability, customers, or outside equity, not on principle.

## Agent Governance & Autonomous Verification

- **Multi-Judge Panels** — Diverse model jury panels with effective-sample-size ($n_{eff}$) correlation diagnostics.
- **Cryptographic Evidence Registers** — Immutable SHA-256 recording of runtime artifacts, test runs, and audit trails.
